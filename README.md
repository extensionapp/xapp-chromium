[![EXTENSION.app](/Assets/Images/banner_icon-2400x800.png)](https://extension.app)


EXTENSION.app is the all-in-one browser extension for Chromium-based browsers.


## Supported browsers
- Chromium
- Google Chrome
- Microsoft Edge
- Opera
- Brave
- Vivaldi
